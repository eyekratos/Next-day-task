# NextDay — Kratos Cinematic V2

Upload every file in this folder to the repository root and commit to `main`.

Files include `index.html`, `manifest.json`, `sw.js`, `background.webp`, `icon.png`, `icon-192.png`, `icon.svg`, and this README.

What changed:
- Replaced the purple hero panel with a blue cinematic frosted-glass panel.
- Kept the Kratos mountain background and dark overlay.
- Header logo uses `icon.png`.
- Updated service worker cache name to force old cached assets to be replaced.

After committing:
1. Open the GitHub Pages URL and hard-refresh with Ctrl+Shift+R.
2. If the installed Android app still shows the moon icon, remove the old home-screen shortcut and use Chrome's Add to Home screen again.
3. Make sure all files are in the repository root, not inside an extra nested folder.
